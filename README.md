# MCM/ICM 美赛数学模型库
> A collection of mathematical models, codes, papers and templates for MCM/ICM (Mathematical Contest in Modeling / Interdisciplinary Contest in Modeling)

## 📖 仓库简介
本仓库整理**美赛MCM/ICM**常用数学模型、算法代码、论文模板、经典赛题解析、写作素材与建模思路，面向准备美国大学生数学建模竞赛的参赛队伍。
> 本仓库仅用于学习交流，**严禁直接复制代码、文字用于竞赛提交**，竞赛需独立完成，抄袭会导致取消成绩。

内容覆盖：
- 经典数学模型原理、适用场景、优缺点
- 可运行代码（Python / MATLAB）
- LaTeX美赛论文模板
- 历年赛题思路复盘
- 绘图、数据预处理、结果可视化脚本
- 摘要、结论、模型假设等写作素材
