# 模板自检证据（通用模板 vs 专用实现）

本目录是 `lstm_template.py`（通用、配置驱动）在 **MCM 2025 Problem C 数据**上的运行输出，
用于证明模板与专用实现 `lstm_312.py` **数值逐位等价**。

## 运行命令

```powershell
cd 01LSTM\代码
python lstm_template.py --config config_mcm2025C.json
```

## 逐位对照（5 种子均值）

| 指标 | 通用模板 `lstm_template.py` | 专用实现 `lstm_312.py`（交付值） | 是否一致 |
|---|---|---|---|
| `val_WMAE_Gold` | 3.562180 | 3.562180 | ✅ |
| `val_MAE_Gold` | 1.776071 | 1.776071 | ✅ |
| `val_MSE_Gold` | 11.611512 | 11.611512 | ✅ |
| `val_WMAE_Total` | 8.577670 | 8.577670 | ✅ |
| `val_MSE_Total` | 65.441387 | 65.441387 | ✅ |
| `train_MAE_Gold` | 1.756252 | 1.756252 | ✅ |
| 2028 澳大利亚 Gold 趋势 | 20.314 | 20.314 | ✅ |
| 2028 澳大利亚 Total 趋势 | 56.350 | 56.350 | ✅ |
| 面板规模 | 82 实体 × 19 期次 | 82 × 19 | ✅ |
| 样本规模 | 1394 = 1312 有标签 + 82 外推 | 同 | ✅ |

> 对照基准：`../数据/lstm_run_config.json`、`../数据/lstm_metrics.csv`、`../数据/lstm_trend_2028.csv`

## 目录内文件

| 文件 | 说明 |
|---|---|
| `metrics_by_run.csv` | 5 个随机种子的逐次指标 |
| `metrics_summary.csv` | mean / std 汇总（`metric` 列为指标名） |
| `trend_history.csv` | 每个 (实体, 目标期次) 的趋势值（跨种子均值 + std） |
| `trend_future.csv` | 2028 年外推趋势值（跨种子均值 + std） |
| `fig_training.png` | 各随机种子的验证集 WMAE 曲线（可见早停在 7–12 轮附近） |

## 迁移复现提示

换数据集时只需新建一份 config（最少 4 个字段：`panel_csv` / `entity_col` / `year_col` / `target_cols`），
先跑 `--dry-run` 检查面板与样本规模，再正式训练。
