## 2. 模型总结（一句话与结构）

> **一句话**：把每个国家“历届金牌数/奖牌总数”的时间序列，连同“是否东道主 / 是否处于备战窗口 / 该国主场优势系数”一起喂给一个**双通道 LSTM**；奖牌通道学成绩趋势，主场通道学主场与备战效应；两者拼接后由全连接层输出**下一届的趋势值**；训练用 **0.7×MSE + 0.3×BCE（主办识别）** 的联合损失，用 **WMAE** 调参选出 **hidden_size=32、patience=6**；产出的趋势值交给 XGBoost-Bootstrap 做最终区间预测。

**数据流**

```
summerOly_medal_counts.csv ─┐
summerOly_hosts.csv ────────┴─► 清洗/合并政治实体 ─► 82 国 × 19 届面板（缺届补 0）
                                   │
                                   ├─► [Host, Prep, α_c] ─► host 通道 LSTM ─┐
                                   └─► [Gold, Total]×3 届 ─► medal 通道 LSTM ─┴─► 拼接 ─► FC ─► 趋势值
                                                                                        │
                                              ┌─────────────────────────────────────────┘
                                              ▼
                          lstm_trend_history.csv（1964–2016 训练 / 2020、2024 验证）
                          lstm_trend_2028.csv   （2028 外推） ──► XGBoost-Bootstrap
```

### 2.1 模型规格（与论文公式对应）

| 项 | 内容 |
|---|---|
| 式(1) 主场优势系数 | $\alpha_c=(\mathrm{Gold}^{host}_c-\mathrm{Gold}^{avg}_c)/\mathrm{Gold}^{avg}_c$，**因果版**：只用目标届之前的主办届与历史成绩；从未主办则为 0 |
| 式(2) 备战期 | $\mathrm{Prep}_t=1$ 若 $t\in[t_{host}-8,\ t_{host}]$（8 年 = 两个奥运周期） |
| 式(3) 输入向量 | $\mathbf{x}_t=[\mathrm{Gold}_t,\mathrm{Total}_t,\mathrm{Host}_t,\mathrm{Prep}_t,\alpha_c]$（5 维） |
| 式(4) 结构 | 双通道 LSTM 各 1 层：medal 通道输入 2 维、host 通道输入 3 维，$n_{steps}=3$；末步隐状态拼接 → `FC(64→2)` 输出（Gold, Total）；另有 host 分类头（sigmoid） |
| 式(5) 损失 | $\mathcal L=0.7\mathcal L_{medal}+0.3\mathcal L_{host}$，$\mathcal L_{medal}$ 为 Gold/Total 的 MSE（标准化尺度），$\mathcal L_{host}$ 为以目标届主办状态为标签的 BCE |
| 式(6) 指标 | $\mathrm{WMAE}=\sum_c w_c|y_c-\hat y_c|/\sum_c w_c$，**$w_c$ = 真实当届金牌数** |
| 超参数 | **hidden_size = 32，patience = 6**（论文点名的配置），Adam(lr=1e-3)、batch=16、dropout=0.2、weight_decay=1e-5、最多 200 epoch |
| 权重选择 | 恢复验证集最优权重（`select=best`） |
| 随机种子 | 0–4 共 5 个，交付值为**5 种子均值**，标准差随附（`*_std` 列） |

### 2.2 数据口径（**下游必须沿用，否则特征对不上**）

| 项 | 取值 |
|---|---|
| 时间范围 | **1952–2024，共 19 届**（1896–1948 与 1906 未使用） |
| 国家口径 | **合并历史政治实体**：苏联/独联体/ROC→俄罗斯；东德/西德/德国联队→德国；捷克斯洛伐克→捷克；南斯拉夫/南联盟/塞黑→塞尔维亚；福尔摩沙/台湾→中华台北。非国家代表队剔除。**同一届多实体求和** |
| 国家数量 | **82 个**（1952 年后至少有 5 届奖牌记录） |
| 面板构造 | 82 × 19 完整网格，**未上榜届次补 0**（原始数据只收录获奖国家） |
| 样本对齐 | **窗口 = 连续 3 届 → 预测下一届（t → t+1）**，修正原文同届对齐的信息泄漏 |
| 划分 | 训练目标届 ≤ 2016（1148 样本）；验证目标届 = 2020、2024（164 样本）；预测 = 2028（82 行） |
| 标准化 | Gold/Total 按**训练窗口**统计量标准化后算损失；交付的趋势值已反变换回**原始奖牌数尺度** |

### 2.3 交付配置的评估结果（验证集 2020/2024，5 种子均值）

| 指标 | Gold | Total |
|---|---|---|
| WMAE（$w$=真实金牌数） | 3.562 | 8.578 |
| MAE | 1.776 | 4.102 |
| MSE | 11.61 | 65.44 |
| RMSE | 3.41 | 8.09 |
| MAPE | 85.3% | 125.4% |
| 训练集 MAE | 1.756 | 4.342 |

> MAPE 在“大量国家金牌数为 0”的场景下没有意义（分母被 `max(|y|,1)` 截断），**建议下游只用 MAE / WMAE / RMSE**。若只看真实金牌 ≥5 的国家：金牌 MAPE 32.1%、总数 MAPE 23.8%。
> 验证集金牌 **pred–true 相关系数 r = 0.897**（回归斜率 0.913，略向均值收缩）。

## 3. 数据字典

### 3.1 `lstm_trend_history.csv`（1312 行；XGBoost 训练/验证样本的特征表）

|---|---|---|

| `IsHost_true` | 0/1 | 该届该国是否东道主 |

| `n_seeds` | int | 参与聚合的种子数（=5） |

## 4. 下游怎么用（XGBoost-Bootstrap）

### 4.1 特征拼装（推荐）

论文 3.1.3 节 XGBoost 的输入 = **① 趋势值（本交付）② 5 个 PCA 主成分（3.1.1 节产出，尚未复现）③ 目标届的主场效应**。

```python
import pandas as pd

BASE = "交付数据/data"
base   = pd.read_csv(f"{BASE}/base_panel_country_year.csv")     # 主键 Country+Year
trend  = pd.read_csv(f"{BASE}/lstm_trend_history.csv")          # 历史趋势值
t2028  = pd.read_csv(f"{BASE}/lstm_trend_2028.csv")             # 2028 趋势值

# 历史样本（XGBoost 训练/验证）：按 (Country, Year) 左连接，趋势值只覆盖 1964–2016 与 2020/2024
hist = base.merge(trend, on=["Country", "Year"], how="inner")

# 2028 预测行：Year=2028，右表键为 Country
pred = base[base.Year == 2024][["Country"]].copy()
pred["Year"] = 2028
pred = pred.merge(t2028, on="Country", how="left")               # 得到 2028 趋势值
pred["IsHost"] = pred["IsHost2028"]; pred["Prep"] = 1; pred["Alpha_c"] = base...  # 主场效应按 §2.2 口径取
```

**注意**：`lstm_trend_history.csv` 只覆盖 1964–2016、2020、2024 共 16 个目标届；若 XGBoost 想用 1952/1956/1960 作样本（前 3 届无 3 届窗口，LSTM 无法产出趋势值），需自行决定丢弃这些行或用 0/缺失填充。

### 4.2 给 3.2 节“零的突破”预留的接口

论文 3.2 节要求“对**点估计值 ≥ 1 的 Bootstrap 样本**做符号秩检验”，因此 XGBoost-Bootstrap 阶段必须**保存完整的 Bootstrap 预测样本矩阵**（例如 1000 次重采样 × 82 国 × {Gold, Total}），而不能只保存 95% 区间端点。请在下一阶段产出：

- `xgb_bootstrap_samples_gold.csv`（1000 × 82，列 = 国家名）
- `xgb_bootstrap_samples_total.csv`（1000 × 82）
- `xgb_point_estimate_2028.csv`（国家、点估计、CI 下/上限、Trend 方向）

### 4.3 主场效应特征的建议口径（与 LSTM 保持一致）

- `IsHost`：目标届是否为该国主办（2028 → 美国 = 1）；
- `Prep`：目标届是否落在该国主办前 8 年窗口（2028 年美国在 2020、2024 已处于备战期，2028 本身也是主办年 → `Prep=1`）；
- `Alpha_c`：直接取 `base_panel` 中该国的矩阵值；**2028 的目标届值建议用“截至 2024 的历史”重算**（本交付中 `Alpha_c` 列是逐届因果值，2024 列即相当于“截至 2024”的口径）。

## 5. 质量、限制与坑（下游务必阅读）

1. **趋势值 ≠ 最终预测**：它是对“长期水平 + 趋势”的正则化估计（例如英国 2028 趋势 28.3，而其 2024 实际仅 14）。最终奖牌预测由 XGBoost 在趋势值 + 主成分 + 主场效应之上完成，**不要用趋势值直接当预测结果**。
2. **历史趋势值中有 in-sample 部分**：1964–2016 的目标届落在 LSTM 的训练集内，2020/2024 才是真正的样本外。若 XGBoost 用这些趋势值训练，需意识到特征存在轻微乐观偏差；严格做法是对 LSTM 也做滚动时间序列 CV 后重新生成（可作为改进项）。
3. **种子噪声较大**：同一配置换种子，验证 WMAE 可差 2–7 枚（见 `README.md` 第 8 节）。交付值已取 5 种子均值，`*_std` 列可用于稳健性分析。
4. **俄罗斯 2024 是数据伪影**：2024 俄被禁赛（数据表中无 Russia/ROC 行 → 记 0），LSTM 按历史趋势给出 26.7 金 / 73.1 牌，是验证集最大误差源。XGBoost 会继承这一异常，建议在论文中显式说明或加“政治因素”哑变量。
5. **`Host_prob` 不可信**：host 分类任务在训练集只有 14 个正样本（1.2%），概率的绝对水平无意义（三变体间可从 0.05 到 0.19）。**不要把 `Host_prob` 当特征**，主场效应用确定性的 `IsHost/Prep/Alpha_c`。
6. **小国趋势值可能恒定**：某国若在窗口内三届均为 0 奖牌，输入向量完全相同 → 输出也完全相同（例如阿尔及利亚 1964/1968/1972 趋势值一致）。这是模型对“无信息输入”的合理反应，但在 XGBoost 中这类特征对区分这些国家无贡献。
7. **α_c 存在重尾**：未做过归一化时最大到 7.34（比利时），交付表中保留原值；LSTM 内部训练时做过 z-score 标准化，下游若直接用建议先做标准化或截断。
