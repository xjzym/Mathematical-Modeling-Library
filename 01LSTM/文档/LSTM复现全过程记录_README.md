## 4. 数据口径与复现决策（已与用户逐条确认）

| 项 | 采用的做法 |
|---|---|
| 数据源 | `summerOly_medal_counts.csv`（主表）+ `summerOly_hosts.csv`（主办/备战） |
| 时间范围 | **1952—2024，共 19 届** |
| 国家口径 | **合并历史政治实体**：苏联/独联体/ROC→俄罗斯；东德/西德/德国联队→德国；捷克斯洛伐克→捷克；南斯拉夫/南联盟/塞黑→塞尔维亚；福尔摩沙/台湾→中华台北。非国家代表队（独立参赛者、难民队等）剔除。同一届多实体**求和** |
| 国家门槛 | 1952 年后至少有 5 届奖牌记录 → **82 个国家** |
| 面板构造 | 82 国 × 19 届完整网格，未上榜届次补 0（数据表只收录获奖国家） |
| 式(1) α_c | **因果实现**：只用目标届之前的届次计算；从未主办过则为 0（避免“用 2024 法国主场成绩解释 2024 法国成绩”的信息泄漏） |
| 式(2) Prep_t | 该国主办届前 8 年窗口内置 1（含主办届本身） |
| 式(3) 输入 | 奖牌通道 `[Gold, Total]`；主场通道 `[Host, Prep, α_c]` |
| 式(4) 结构 | 双通道 LSTM 各 1 层（hidden=32）→ 末步隐状态拼接 → FC(64→2)；另加 host 分类头（sigmoid） |
| 式(5) 损失 | `L = 0.7*MSE + 0.3*BCE`；MSE 在**标准化尺度**上计算（数值稳定），指标在原始尺度上报 |
| 式(6) WMAE | **w_c = 真实当届金牌数**（用户选定），`Σw=0` 时该指标记为 NaN；另出 `w_c=真实值+1` 的对照 |
| 样本对齐 | **窗口 3 届 → 预测下一届（t→t+1）**，修正原文同届对齐造成的信息泄漏 |
| 训练/验证 | 训练目标届 ≤2016（1148 样本）；**验证 = 目标届 2020、2024（164 样本）**（用户选定，按时间留出） |
| 预测 | 2028（82 个纯预测样本：窗口 = 2016/2020/2024） |
| 训练细节 | Adam(lr=1e-3)、batch=16、dropout=0.2、weight_decay=1e-5、最多 200 epoch、早停 patience=6；β(candidate)=第 3 步操作文档将统一说明 |
| 早停判据 | 验证集 `mean(WMAE_Gold, WMAE_Total)`（w=真实金牌数）最小；全为 NaN 时退回 MSE |
| 随机种子 | 0,1,2,3,4（5 次，报告 mean ± std） |

### 5.5 p̂ 三消融：对“原文 0.1”的实证回答

2028 年美国（真实主办国）的 host 概率（5 种子均值）：

| 变体 | Host_prob(美国 2028) | 验证集 2 个真实主办样本的概率 | 训练轮数 |
|---|---|---|---|
| main | 0.052 | 日本 2020 = 0.065；法国 2024 = 0.070 | 13.0 |
| A（bias 初始化 0.1） | 0.088 | 0.099；0.101 | 18.4 |
| B（标签平滑 0.1） | **0.187** | 0.200；0.203 | 17.8 |

结论：
1. **把 0.1 当作分类头 bias 先验（解释 A）在预测任务上最好**：WMAE 最低、MSE 最低、host AUC 最高（0.957）、训练更充分（平均 18.4 轮 vs 13.0 轮），说明“0.1”确实起到了**防止稀有正类塌缩**的作用——这正是原文把它写在损失旁边的合理动机；
2. 标签平滑（解释 B）把 host 概率抬得更高但 WMAE 略逊于 A；
3. 三种变体都不影响奖牌趋势与 WMAE 的排序结论 → **原文那个“常数 0.1”写法的歧义，不影响模型的主要结论**，可以放心按 A 实现。

## 6. 调参网格复现（论文图 3 / 图 4）

### 6.1 为什么要跑两套协议

论文图 3 的形态是「同一个 hidden_size 下，不同 patience 的 WMAE 各不相同」。但**权重选择协议**决定了 patience 是否真的会改变结果：

| 协议 | 含义 | 后果 |
|---|---|---|
| `--select best` | 早停后**恢复验证集最优权重** | patience 只决定“何时停”，选出的权重相同 → 对 hidden=64/128 **所有 patience 的指标完全相同**（实测 best_epoch 恒为 10~11） |
| `--select last` | 保留**早停时刻的权重**（更接近论文图 3 的形态） | 每个 (hidden, patience) 都是不同模型，指标随 patience 波动 |

两套都跑了（各 75 次训练，见 `out/grid_results*.csv`）。**下文以 `last` 协议为主**，因为它才可能出现论文图 3 那种“每个 patience 不同”的形态。

## 7. 省算力技巧：一条 patience=10 的训练可派生整条 patience 扫描（已实证）

**原理**：early stopping 只决定“在哪里停”，不改变训练轨迹。同一随机种子、同一数据顺序下，`patience=10` 的运行轨迹**包含** `patience=6/7/8/9` 的停止点，于是

- `select=best`：各 patience 结果完全等价（都取运行最优轮次）；
- `select=last`：`patience=k` 的结果 == 第（最后一次改进轮次 $+\,k$）轮的权重与指标。

**实证**（`verify_patience_from_single_run.py`）：只用 **15 次训练**（hidden ∈ {32,64,128} × 5 个种子，每个只跑 `patience=10`）派生全部 **75 组**（15 配置 × 5 种子）结果，并与逐组**单独训练**的网格对账：

| 项目 | 结果 |
|---|---|
| 对比组数 | 75 |
| 最大绝对差（WMAE_Gold / WMAE_Total） | $2.4\times10^{-7}$（PyTorch CPU 多线程浮点归约噪声） |
| 15 个单元格的 5 种子均值与 `grid_summary.csv` 之差 | 最大 $4.7\times10^{-4}$，**3 位小数显示完全一致** |

也就是说，第 6 节那 75 次训练，**理论上每协议只需 15 次**（省 80% 计算）。本复现为求稳妥仍按“逐组单独训练”出正式结果，派生结果仅用于验证该性质。

**前提与限制**

1. 必须同一随机种子、同一数据顺序（本实现 shuffle 由全局 RNG 决定，满足）；
2. 训练中不能有依赖“总轮数”的调度（例如按 `max_epochs` 做 cosine 退火）；
3. 想拿到**模型权重本身**（而不只是指标），需要保存每轮 checkpoint；若只画图/比指标，记录每轮验证分数即可；
4. 只对“同一 hidden、其余超参不变、仅改 patience”成立；hidden 或数据口径变化必须重跑。

**产物**：`verify_patience_from_single_run.py`、`out/derived_patience_sweep.csv`（75 组逐项对账）、`out/derived_grid_summary.csv`（派生网格）。

## 8. 为什么论文的 WMAE 差距大、我们的小？（专项排查）

论文图 3 的读数：WMAE_Gold 在 $2.78\sim6.00$（极差 3.22），WMAE_Total 在 $6.31\sim11.59$（极差 5.28），且**原图没有误差棒**——几乎可以肯定是**每个配置只跑一次**。我们的图是 **5 个随机种子的均值 ± 标准差**，于是差距被平滑掉了。

### 8.1 量化：种子噪声 vs 配置间差异（`next` 对齐，`last` 协议）

| 口径 | WMAE_Gold | WMAE_Total |
|---|---|---|
| 配置间极差（15 配置的 5 种子均值） | **0.87** | **1.89** |
| 单配置内**种子**极差（15 配置的平均） | 1.06 | 2.78 |
| 单配置内**种子**极差（最大，出现在 128×9） | 2.81 | 6.97 |
| 单次运行取值范围（全部 75 次） | 3.42 ~ 6.37 | 7.47 ~ 14.88 |
| 论文图 3 的取值范围 | 2.78 ~ 6.00 | 6.31 ~ 11.59 |

**结论：同一配置换个随机种子造成的波动，比配置之间的真实差异大 2~3 倍。**

### 8.2 蒙特卡洛：模拟“每配置只跑一次”的图 3

从 5 个种子中为每个配置随机抽 1 个，重复 3000 次，统计 15 个配置之间的极差分布：

| 指标 | 中位数 | 5%~95% 区间 | 最大值 | 论文实测极差 |
|---|---|---|---|---|
| WMAE_Gold | 1.60 | [1.02, 2.86] | 2.95 | **3.22**（略超上限） |
| WMAE_Total | 4.06 | [2.52, 7.35] | 7.40 | **5.28**（区间内） |

即：**论文 Total 的差距完全落在“单次运行噪声”的分布里**；Gold 的 3.22 略高于我们模拟的上限，说明除噪声外还有其它口径差异（见 8.3）。

### 8.3 其它叠加因素（已逐项实测）

| 因素 | 实测结果 | 是否解释“差距大” |
|---|---|---|
| **训练预算敏感性**：若把 patience 当成“很小的训练轮数” | `probe_epoch_budget.py`：预算 2~10 轮时，5 种子均值极差仅 0.94/2.12，但**单次运行**跨度 2.94~6.37（Gold）、7.48~14.01（Total） | 与“单次运行”叠加后，可完全覆盖论文的数值范围 |
| **对齐方式**：原文式(4a)/(4c) 同届对齐（输入含目标届＝泄漏） | `--align same` 网格：Gold 均值 0.81~1.72、Total 2.07~4.78，**比论文报的还低** | 说明论文数字既不是“完全泄漏版”也不是我们的“无泄漏版”，其口径无法完全确定 |
| **WMAE 权重口径** | 本复现按用户选择用 $w_c=$ 真实当届金牌数 → 有效样本量只有约 30 个强国，指标本身方差很大 | 权重或样本集一变，水平与波动都会变 |
| **标准化 + 早停判据** | 目标标准化、并以验证 WMAE 作为早停判据 → 每个配置都停在自己较优处 | 会机械性地压缩配置间差异 |
| **数据口径与切分** | 合并历史政治实体、1952 起、时间留出 2020/2024；且俄罗斯 2024 禁赛造成 73 枚误差的伪影 | 与论文未知口径不同，无法逐项对齐 |

### 8.4 结论

我们观察到的“差距小”，**是 5 种子平均 + 配对检验之后的诚实结果**：配对 $t$ 检验显示所有配置两两差异都不显著（$|t|<2.776$）。论文图 3 那种“每个 patience 都不同”的锯齿，更可能来自**单次运行噪声**与**训练预算敏感度**，而不是超参数的真实效应。

如果要在报告里既贴近论文形态又不误导，建议：画单次运行的“论文风格图”，**同时叠加 5 种子的均值与误差棒**，并在图注里写明差异在随机波动范围内。

## 9. 已发现的坑（复现中真实踩到）

1. **hosts 表 2020 行带括注**：`"Tokyo, Japan (postponed to 2021 …)"`，直接取逗号后字段会得到 `"Japan (postponed…)"`，导致日本 2020 的 `Host`/`Prep` 全部丢失（训练正样本从 15 掉到 14）。已在代码中用 `.split("(")[0]` 修复。
2. **奖牌表只收录“获奖国家”**：未参赛/未获奖都是“缺席”，必须按完整国家 × 届次网格补 0，否则序列不连续。
3. **NOC 尾部空格**：如 `"Great Britain "`，不 strip 会分裂成两个国家。
4. **东道主名称≠NOC 名称**：hosts 写 `United Kingdom`，奖牌表只有 `Great Britain`，必须显式映射。
5. **原文对齐方式有泄漏风险**：式(4c)/(5b) 把 $\hat y_t$ 与 $y_t$ 同届对齐，而 $\mathbf x_t$ 又含 $Gold_t$。本复现改为 $t\to t+1$。
6. **俄罗斯 2024 是数据伪影**：2024 俄被禁赛（数据表中无 Russia/ROC 行 → 记为 0），模型按历史趋势预测 26.7 金/73.1 牌，成为验证集最大误差来源（73.1）。这属于“政治因素”，与原文 7.2 节自述的局限一致。
