## 二、背景（论文原意）

论文用 PCA 降维 + LSTM 趋势 + **XGBoost** 拟合非线性关系，再用 **Bootstrap 重采样**给出预测值的 95% 区间，最终输出 2028 年洛杉矶奥运会各国金牌数与奖牌总数的点估计与区间，并识别谁会进步、谁会退步。

论文给出的关键设定（必须遵守）：

1. **目标函数**（式 7）：
   $$L(\theta)=\sum_{i=1}^{n} l(y_i,\hat y_i)+\sum_{k=1}^{K}\Omega(f_k)$$
   即“损失 + 正则项”，用二阶泰勒展开增量训练（XGBoost 的标准做法）。
2. **超参数**（论文原文给定，作为默认值，可做成网格）：
   `nrounds=75`、`max_depth=2`、`eta=0.1`、`gamma=0.5`（**奖牌总数模型改为 0.25**）、`colsample_bytree=1`、`min_child_weight=1`、`subsample=0.5`。
3. **调参**：以 **RMSE** 为评价标准做网格搜索，并做 **10 折交叉验证**。
4. **不确定性**：用 **Bootstrap 独立重采样 + 重训 1000 次**，得到每个国家预测值的经验分布，取 95% 分位作为区间。
5. **输出**：2028 年金牌数/奖牌总数 **前 20 名**的预测值与区间（论文表 2、图 6），并据此判断各国的上升/下降趋势。

## 六、注意事项与红线

1. **不要**直接拿 LSTM 的趋势值当预测结果——它只是特征（例：英国 2028 趋势 28.3，而其 2024 实际仅 14）。
2. **不要**把 `Host_prob`（LSTM 的主办分类概率）当特征，它在训练集只有 14 个正样本，绝对水平不可信；主场效应用确定性的 `IsHost` / `Prep` / `Alpha_c`。
3. **不要**在特征里使用 `Gold_trend_std` 之外的“未来信息”；`*_std` 是 5 个种子的离散度，可作为稳健性特征，但要在报告中说明。
4. **已知数据伪影**：俄罗斯 2024 被禁赛（数据表中记为 0 奖牌），会让验证集出现巨大误差；请在报告中显式说明，必要时加“政治因素”哑变量做对照。
5. **样本量很小**（1148 训练样本、82 个国家、十几维特征），XGBoost 必须**强正则**（`max_depth=2` 正是为此），请在报告中解释这一选择的动机。
6. 如果 Bootstrap 1000 次重训太慢，可以退化为“对训练集重采样 + 复用已调好的超参”，但**必须说明这是对论文做法的近似**。
